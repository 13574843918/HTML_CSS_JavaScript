textarea 控件

实训目标：掌握 textarea 多行文本框的基本使用，了解 cols、rows 属性的含义


关键知识点
<textarea>

多行文本输入框，开始和结束标签之间的内容为默认文字

cols

每行字符数（浏览器理解不同，推荐用 CSS width 替代）

rows

显示行数（推荐用 CSS height 替代）

readonly / disabled

只读 / 禁用属性

动手练练
  • 将 cols="60" rows="8" 改为 CSS 样式 style="width:400px; height:120px;"，观察效果
  • 给 textarea 添加 readonly 属性，观察文本变为只读
  • 清空 textarea 标签之间的默认文字，添加 placeholder="请输入评论..."

select 控件（下拉菜单）

实训目标：掌握 select 下拉菜单的基本使用，包括单选下拉、默认选中与多选列表框

关键知识点
<select>

创建下拉菜单，内嵌 option 标签定义选项

size

下拉框可见选项数（配合 multiple 使用）

multiple="multiple"

允许多选，按 Ctrl 键可同时选多项

selected="selected"

option 属性，设置默认选中项

动手练练

  • 给多选列表框的 size 改为 size="3"，观察可见选项数变化
  • 在"特长"下拉中再添加两个 option 选项（如"体育"和"演讲"）

请用纯 HTML + CSS 制作一个博客发文页面，要求如下：

【功能要求】
1. 文章标题输入框（单行 input）
2. 文章正文多行文本框（textarea，高度至少 200px）
3. 文章分类下拉菜单（select），选项包含：
   - 技术：前端开发、后端开发、移动端
   - 生活：美食、旅行、随笔
   （使用 optgroup 分组）
4. 是否公开单选按钮（公开 / 私密）
5. 文章标签复选框（前端、HTML、CSS、JavaScript）
6. 发布和存草稿两个按钮

【样式要求】
1. 白色主题，卡片式布局，最大宽度 700px 居中
2. 标题输入框宽度撑满，高度 44px
3. 正文文本框 100% 宽，高度 240px，不允许水平拉伸（resize: vertical）
4. 分类下拉、单选、复选框区域有明显分组背景色
5. 发布按钮蓝色背景，存草稿按钮灰色背景

【技术要求】
1. 只用 HTML + CSS，不需要 JavaScript
2. 所有表单控件必须在 form 标签内，method="post"
3. 代码结构清晰，有注释
