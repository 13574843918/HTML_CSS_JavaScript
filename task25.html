任务二十五

违停查询

掌握 CSS 定位模式（relative / absolute / fixed），实现元素精确定位和悬停交互效果。

预计学习时长：60分钟
position 定位属性

学习目标

  • 掌握 position: relative 相对定位的使用方法
  • 掌握 position: absolute 绝对定位及"父相子绝"定位模式
  • 了解 position: fixed 固定定位的应用场景
  • 理解 top / left / right / bottom 边偏移属性的作用
  • 能够综合运用定位制作悬浮交互效果
⚡ HBuilderX 使用技巧 · 本节专属 position & 元素定位
📍
position 快速补全

输入 pos:r 按 Tab 补全 relative，pos:a 补全 absolute，pos:f 补全 fixed。

📐
偏移量快捷输入

输入 t:0、l:0、r:0、b:0 分别按 Tab，快速补全 top/left/right/bottom 为 0。

🗂️
z-index 层叠

输入 z:1 按 Tab，补全 z-index: 1;。数值越大越靠上，只对定位元素生效。

🔍
F12 查看定位

DevTools 的 Elements 面板中，选中元素后在 Styles 可看到 position 属性；在 Layout 标签可看到偏移量。

🖱️
:hover 伪类

在 DevTools 的 Styles 面板点击 :hov 按钮，可强制触发 :hover 状态，方便调试悬停样式。

🎯
父相子绝记忆法

记住：父设 relative（不设偏移），子设 absolute（设偏移）。口诀：父相子绝，相对父定位。

01

example 7-10：相对定位（position: relative）

实训目标：掌握相对定位的特点：元素相对于其原始文档流位置进行偏移，但原来占据的空间依然保留，不影响周围元素布局。

关键知识点
position: relative

相对定位，相对于元素自身的原始位置进行偏移

保留文档流空间

偏移后，元素原来占据的空间依然保留，不影响其他元素

top / left / right / bottom

边偏移属性，指定相对于原位置的偏移量

常见用途

作为绝对定位子元素的参考父元素（父相子绝）

动手练练
  • 修改 left: 100px 为 left: 50px，观察 child02 偏移量减小
  • 将 top: 20px 改为 top: -20px（负值），观察元素向上偏移
  • 删除 position: relative;，观察 left/top 失效，元素回到正常位置
挑战练习
  • 给 child01 也添加相对定位，让它向右偏移 20px，观察 child02 是否受影响
02

example 7-11：父相子绝 — 子元素相对父元素绝对定位

实训目标：掌握"父相子绝"定位模式：父元素设 position:relative（不设偏移），子元素设 position:absolute 并设置偏移量，子元素将相对父元素精确定位，无论浏览器如何变化，位置始终保持。

关键知识点
position: absolute

绝对定位，脱离文档流，相对最近已定位祖先元素定位

父相子绝模式

父设 relative（不设偏移），子设 absolute（设偏移）

脱离文档流

绝对定位元素不再占用文档流空间，后续元素填充其原位置

z-index 层叠

绝对定位元素可用 z-index 控制叠加顺序

动手练练
  • 修改 left: 150px 为 right: 0，让 child02 定位到父元素右边缘
  • 删除父元素的 position: relative;，观察 child02 改为相对浏览器窗口定位
  • 给 child02 添加 z-index: 10;，再将 child01/03 的 z-index 设为更大，观察谁覆盖谁
挑战练习
  • 用父相子绝实现一个右上角角标效果：父元素是一个卡片，子元素是右上角的"NEW"标签
03

example 7-12：违停查询（综合定位案例）

实训目标：综合运用浮动 + 父相子绝定位，制作违停查询界面。左侧地图区域放置多个绝对定位的图标，鼠标悬停时切换背景图实现交互效果；右侧文字区域浮动对齐。

关键知识点
父相子绝

.left 设 relative，.spot 设 absolute，实现标记精确定位于地图上

:hover 交互

鼠标悬停时切换背景/颜色，实现简单的交互视觉反馈

z-index: 2

提升标记层级，确保其显示在地图背景之上

transition

添加过渡动画，让 hover 效果更流畅自然

动手练练
  • 修改 .spot1 的 left 和 top 值，将标记移到地图其他位置
  • 给某个 .spot 添加 position: fixed;，观察它脱离父元素改为相对浏览器窗口定位
  • 修改 .spot:hover 的 background 颜色，自定义悬停效果
挑战练习
  • 给每个 .spot 添加一个 :hover 时显示的工具提示（用 ::after 伪元素 + absolute 定位实现）
拓展练习 · 相册图片悬浮效果

制作一个带悬浮层效果的相册：图片右上角有删除按钮（父相子绝），鼠标悬浮时出现半透明蒙层和说明文字（:hover + absolute），综合练习定位的精确控制能力。

  • 任务一：修改 .delete-btn 的 top 和 right 值，将删除按钮移到左上角
  • 任务二：修改 .overlay 的 background，将蒙层改为蓝色半透明
  • 任务三：在 .overlay 中添加 font-size: 16px 和表情图标，丰富蒙层显示内容
  • 任务四（挑战）：给 .photo-wrap:hover 添加 transform: scale(1.05)，实现悬停放大效果
