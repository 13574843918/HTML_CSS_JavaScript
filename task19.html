趣味选择题

掌握 input 控件的全部类型及 label 标签的绑定用法

预计学习时长：75分钟
input全类型与label绑定

学习目标

  • 掌握 input 控件的全部 type 类型（text/password/radio/checkbox/file/submit/reset/button/image/hidden）
  • 掌握 name 属性对单选/多选按钮的分组作用
  • 掌握 label 标签与 for/id 属性绑定方法
  • 能用 CSS 美化单选题和多选题界面
⚡ HBuilderX 使用技巧 · 本节专属 radio & checkbox
🔘
radio 分组

同组单选按钮必须设置相同的 name 属性，否则无法互斥选择。

☑️
checked 默认选中

radio 和 checkbox 添加 checked="checked" 可设置默认选中状态。

🏷️
label + for/id

label 的 for 属性值必须与 input 的 id 值完全一致，才能绑定点击。

📦
label 包裹写法

也可将 input 直接放在 label 内部，无需 for/id 即可绑定，更简洁。

input 控件全类型演示

实训目标：了解 input 标签支持的全部 type 类型，包括文本框、密码框、单选、复选、文件域、提交、重置、普通按钮、图像域、隐藏域

关键知识点 — input type 速查表
type 值控件类型说明
text单行文本框常用属性：value、maxlength
password密码框内容以圆点显示
radio单选按钮同组必须相同 name，checked 设默认选中
checkbox复选框可用 checked 设默认选中
file文件域出现文本框和"浏览"按钮
submit提交按钮提交表单数据
reset重置按钮清空所有表单内容
button普通按钮常配合 JavaScript 使用
hidden隐藏域对用户不可见，传递数据用

<label> 标签的使用

实训目标：掌握 label 标签的 for/id 绑定方法，扩大表单控件的点击范围，提升用户体验

关键知识点
<label for="id">

label 的 for 值与 input 的 id 一致时，点击文字即激活控件

id 属性

表单控件的唯一标识，必须唯一，与 label 的 for 配对

label 包裹写法

将 input 直接嵌套在 label 内，无需 for/id 也能绑定

radio + name

AI实训：让AI完成在线问卷开发

问卷/投票表单是网页中非常常见的功能。下方提示词可直接让 AI 工具生成一套完整的在线问卷界面，含单选、多选、文字输入和提交功能。

📋 提示词范本（可直接复制使用）
请用纯 HTML + CSS 帮我制作一个课堂满意度调查问卷页面，要求如下：

【内容要求】
1. 标题：本学期课堂满意度调查
2. 第1题（单选）：您对本学期课堂内容的总体满意度如何？
   选项：非常满意 / 满意 / 一般 / 不满意
3. 第2题（多选）：您觉得哪些方面还需改进？（可多选）
   选项：教学内容 / 讲课速度 / 互动环节 / 课程资料
4. 第3题（文字输入）：您有哪些具体建议？（多行文本框）
5. 提交按钮

【样式要求】
1. 整体白色背景，卡片式布局，最大宽度 600px 居中
2. 每道题用 <fieldset> 包裹，有题号和题目文字
3. 单选/多选选项横向排列，label 和 input 绑定
4. 提交按钮绿色背景 #16a34a，白色文字，圆角

【技术要求】
1. 使用语义化 HTML（fieldset/legend/label/input）
2. 所有单选按钮同组 name 相同
3. label 的 for 与 input 的 id 正确绑定
4. 代码简洁易读，含必要注释
