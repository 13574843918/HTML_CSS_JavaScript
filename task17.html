6-01

创建基本表格

实训目标：掌握 table、tr、td 三个核心标签的嵌套结构，创建最基本的表格

关键知识点
<table>

定义表格的开始与结束

<tr>

定义一行，嵌套在 table 中

<td>

定义单元格，嵌套在 tr 中

border属性

设置表格边框，默认值为 0（无边框）

动手练练
  • 将 border="1" 改为 border="3"，观察边框粗细变化
  • 在表格末尾再添加一行数据（小王、语文、95）
  • 将 border="1" 删除，观察无边框效果
6-02

<tr> 标签的属性

实训目标：掌握 table 和 tr 标签的常用属性，控制表格外观

关键知识点
width/height

设置表格宽高

align(table)

设置表格水平对齐（center居中）

valign

垂直对齐：top/middle/bottom

bgcolor

设置行或单元格背景色

  • 将 valign="top" 改为 valign="bottom"，观察垂直对齐变化
  • 给第二行添加 bgcolor="#EEFFEE" 属性
6-03

单元格合并（colspan / rowspan）

实训目标：掌握 rowspan 和 colspan 实现单元格合并的方法

关键知识点
colspan

横向合并单元格（水平跨列数）

rowspan

纵向合并单元格（垂直跨行数）

<th>

表头单元格，文字默认加粗居中

合并规则

合并后需删除被合并的多余 td

动手练练
  • 将 rowspan="3" 改为 rowspan="2"，并恢复第三行被删除的住址 td，观察效果
  • 在表头行前添加一行，使用 colspan="4" 合并成一个大标题单元格"联系人信息"
  • 将第一列的"姓名"改为 <th> 标签，观察加粗居中效果

6-05

CSS 控制表格边框

实训目标：使用 CSS border 和 border-collapse 控制表格边框样式

关键知识点
border(CSS)

灵活控制边框颜色、粗细和样式

border-collapse:collapse

合并双线变单线，去掉间隙

border-collapse:separate

边框分离（默认），有双线间隙

tr无border

行标签 tr 不支持 border 样式属性

动手练练
  • 在 table 的 CSS 中添加 border-collapse: collapse;，观察双线变单线效果
  • 将边框颜色 #30F 改为 #f97316（橙色），观察效果
  • 只保留 table 的 border，删除 th/td 的 border，观察只有外框的效果
6-06

CSS 控制单元格边距

实训目标：掌握 CSS padding 控制单元格内边距，理解 margin 对单元格无效

关键知识点
padding(td/th)

单元格内边距有效，等效 cellpadding

margin(td/th)

单元格外边距无效

cellspacing

单元格间距只能用HTML属性设置

tr无padding

行标签 tr 无 padding 和 margin 属性

动手练练
  • 将 padding: 50px 改为 padding: 10px 20px，观察效果
  • 取消注释 margin: 50px，并添加 border-collapse: collapse，观察 margin 无效
  • 在 table 标签上添加 HTML 属性 cellspacing="10"，观察间距效果
6-07

CSS 控制单元格宽高

实训目标：理解同行取最大高度、同列取最大宽度的规则

关键知识点
同行取最大高

A(80px)与B(40px)同行，最终行高80px

同列取最大宽

A(100px)与C(200px)同列，最终列宽200px

动手练练
  • 将 .three 的 width 改为 50px（小于 .one 的 100px），观察结果是否还是 100px
  • 将 .two 的 height 改为 120px（大于 .one 的 80px），观察行高变化
  • 给 D 房间添加 class="five"，并定义 .five { width: 300px; }，观察右列宽变化
