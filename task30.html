任务 30

宝石旋转

运用 CSS3 的 @keyframes 规则和 animation 属性定义复杂、可重复播放的动画效果。

70分钟 3个示例

💡 本节核心目标

CSS3 动画（animation）是比过渡（transition）更强大的动画方案。过渡只能定义 A→B 的状态变化，而动画可以定义多个关键帧（A→B→C→D→…），实现复杂的多阶段动画。动画还可以自动播放、无限循环、正反交替，无需用户交互触发。本任务将带你掌握 @keyframes 和 animation 的完整用法，并制作一个宝石旋转综合案例。

8-16

animation-name 与 animation-duration

实训目标：掌握 @keyframes 规则的定义语法，以及 animation-name 和 animation-duration 两个核心属性的用法。

关键知识点
@keyframes 名称 { }

创建动画，定义关键帧序列。from 等同 0%，to 等同 100%。

from / 0%

动画起始帧。from 是 0% 的别名，两者等效。

to / 100%

动画结束帧。to 是 100% 的别名，两者等效。

百分比关键帧

可定义多个中间状态：25%, 75% { ... } 同一百分比可合并书写。

animation-name

将元素与 @keyframes 规则绑定。none（默认）表示无动画。

animation-duration

动画完成一次所需时间（s 或 ms）。必须设置，否则默认 0 不可见。

动手练练
  • 将 animation-duration: 10s; 改为 3s，观察动画速度变化。
  • 在 @keyframes 中添加 25% { background: #09f; }，观察中间帧颜色变化。
  • 将 animation-name 改为一个不存在的名称，观察动画是否还播放。
8-17

animation-iteration-count 与 animation-direction

实训目标：掌握 animation-iteration-count（播放次数）和 animation-direction（播放方向）的用法，理解 animation-fill-mode 和 animation-play-state 的作用。

关键知识点
animation-iteration-count

播放次数。infinite 为无限循环。默认值为 1。

animation-direction: normal

每次都正向播放（默认值）。0% → 100%。

animation-direction: reverse

每次都反向播放。100% → 0%。

animation-direction: alternate

奇数次正向、偶数次逆向。需播放次数 ≥ 2。

animation-direction: alternate-reverse

奇数次逆向、偶数次正向。需播放次数 ≥ 2。

animation-fill-mode: forwards

动画结束后保持最后一帧的样式，不恢复原样。常用於入场动画。

animation-play-state

running（默认，播放中）；paused（暂停，停在当前帧）。

animation-delay 负值

-2s 表示跳过前 2 秒，直接从动画中间开始播放。

动手练练
  • 将 animation-iteration-count: 2 改为 infinite，观察是否无限循环。
  • 将 animation-direction: alternate 改为 reverse，观察播放方向变化。
  • 添加 animation-fill-mode: forwards;，观察动画结束后是否停在最后一帧。
🔥 挑战练习
  • → 制作一个「 spinner 旋转加载动画」：使用 @keyframes spin { from { transform: rotate(0); } to { transform: rotate(360deg); } }，配合 animation: spin 1s linear infinite;，并添加 .spinner:hover { animation-play-state: paused; } 实现悬浮暂停。
8-18

宝石旋转综合案例

实训目标：综合运用本案例所有知识点，制作一个多层叠加的宝石旋转动画效果。理解多动画并行、旋转方向控制、呼吸灯效果和发光效果的实现原理。

animation 简写属性总结
animation 简写

animation: name duration timing-function delay iteration-count direction fill-mode;

必填项

animation-name 和 animation-duration 必须指定，否则动画不播放。

顺时针旋转

from { rotate(0) } to { rotate(360deg) } 实现正向旋转。

逆时针旋转

from { rotate(360deg) } to { rotate(0) } 交换起止值实现反向。

infinite 无限循环

animation-iteration-count: infinite 配合持续旋转/闪烁效果使用。

alternate 往复效果

animation-direction: alternate 实现缩放/颜色等属性的来回交替效果。

box-shadow 动画

通过 @keyframes 改变 box-shadow 大小和颜色，实现发光闪烁效果。

多动画叠加

多个元素可同时运行不同动画，互不影响，各自按自己的参数运行。

动手练练
  • 将外圆环的 animation-duration: 10s 改为 3s，观察旋转速度变化。
  • 将内圆环的 from { rotate(360deg) } 改为 from { rotate(0) }，观察旋转方向是否变为顺时针。
  • 将宝石的 alternate 去掉，观察呼吸灯效果是否变成单向放大。
🔥 挑战练习
  • → 在上面的宝石旋转案例中，添加第 4 个图层（发光层）：使用 box-shadow 动画，让发光效果在橙色和紫色之间交替闪烁，持续时间为 2s。
🛠️ HBuilderX 使用技巧

① 在 HBuilderX 中调试 @keyframes 动画时，可以使用「实时预览」功能（运行→实时预览），保存代码后浏览器自动刷新，无需手动 F5。

② 使用 Ctrl + / 快速注释/取消注释 CSS 代码，在调试动画关键帧时非常有用。

③ animation 简写属性中，animation-play-state 不能写在简写中，必须单独声明。建议调试时先写分开的属性，确认无误后再合并为简写。
