比较运算符

实训目标：演示各种比较运算符，重点区分 ==（宽松等于）和 ===（严格等于）。

关键知识点
== 宽松等于

只比较值，会自动进行类型转换，2 == "2" 为 true

=== 严格等于

同时比较值和类型，2 === "2" 为 false

!= 宽松不等

只比较值，2 != "2" 为 false

!== 严格不等

同时比较值和类型，2 !== "2" 为 true

比较大小运算符

<、<=、>、>=，用于数值大小比较

隐式类型转换

== 会触发，如 "" == false 为 true，推荐使用 ===

动手练练
  • 修改 c 的值为数字 2（去掉引号），观察 a==c 和 a===c 的结果变化
  • 测试特殊比较：alert(null == undefined) 和 alert(null === undefined)
  • 尝试 alert("" == false)，理解隐式类型转换的陷阱
  • 将所有 == 替换为 ===，养成严格比较的习惯
挑战练习
  • 用 prompt() 获取用户输入，使用 === 判断是否等于 "admin"，观察类型转换问题
  • 解释为什么 0 == "" 为 true，但 0 === "" 为 false，理解隐式类型转换机制
HBuilderX 开发技巧
  • JavaScript 中的 == 会进行隐式类型转换，容易产生难以发现的 Bug。建议在 HBuilderX 中安装 ESLint 插件，设置 eqeqeq 规则强制使用 ===，从工具层面避免这类问题。

逻辑运算符

实训目标：掌握 &&（逻辑与）、||（逻辑或）、!（逻辑非）的用法和短路求值特性。

关键知识点
&& 逻辑与

两者都为 true 才为 true；有 false 则结果为 false

|| 逻辑或

至少一个为 true 就为 true；全 false 才为 false

! 逻辑非

取反，!true 为 false，!false 为 true

短路求值

&& 遇 false 短路；|| 遇 true 短路，不再判断后续

真值表

掌握 && 和 || 的所有组合结果，是逻辑判断基础

短路实际应用

var name = input || "匿名用户"；input 为空则使用默认值

动手练练
  • 修改 a 和 b 的值，测试不同的逻辑组合
  • 测试短路求值：alert(true || alert("不会执行")) — 第二个 alert 不会执行
  • 用逻辑或设置默认值：var name = ""; alert(name || "匿名用户")
  • 用逻辑与安全访问：var obj = null; alert(obj && obj.property) — 不会报错
挑战练习
  • 实现登录验证：用户名和密码均不为空才允许登录，用 && 判断 username && password
  • 用 || 实现默认值：var name=prompt("请输入姓名"); alert(name || "游客")
HBuilderX 开发技巧
  • 逻辑运算符的短路特性在开发中非常实用。|| 常用于设置默认值，&& 常用于条件执行。在 HBuilderX 中按 Ctrl+D 可以快速复制当前行，方便测试不同条件组合。

赋值运算符

实训目标：演示复合赋值运算符 +=、-=、*=、/=、%= 的用法。

关键知识点
= 赋值

将右侧值赋给左侧变量，是最基本的赋值运算符

+= 加后赋值

a+=b 等价于 a=a+b，先加后赋值是简写形式

-= *= /= %=

减/乘/除/取模后赋值，都是"运算+赋值"的简写

复合赋值本质

复合赋值运算符完全等价于"运算+赋值"的展开形式

字符串 +=

对字符串使用 += 会进行拼接，如 s+="OK"

使用建议

复合赋值简洁但不宜嵌套过深，初学者建议先展开理解

动手练练
  • 修改初始值 a=10, b=3，重新运行观察每步结果
  • 理解等价关系：将 a+=b 手动展开为 a=a+b，验证结果一致
  • 测试字符串拼接：var s="Hello"; s+=" World"; alert(s);
  • 使用 a%=b 判断奇偶：var n=7; alert(n%2===0?"偶数":"奇数")
挑战练习
  • 用 += 累加计算 1 到 100 的和：var sum=0; for(var i=1;i<=100;i++){ sum+=i; } alert(sum)
  • 用 *= 计算 2 的 10 次方：var p=1; for(var i=0;i<10;i++){ p*=2; } alert(p)
HBuilderX 开发技巧
  • 复合赋值运算符是"运算+赋值"的简写。在 HBuilderX 中，输入 a+= 后会有智能提示。建议初学者先将复合赋值展开理解，熟练后再使用简写形式。

关键知识点
? : 语法

条件 ? 表达式1 : 表达式2，条件为 true 返回表达式1

与 if...else 对比

三目运算符适合简单条件赋值，if...else 适合复杂逻辑

简洁性

三目运算符可以用一行代码替代简单的 if...else 结构

嵌套限制

运算符优先级

实训目标：理解运算符优先级规则——乘法优先于加法，括号可以改变优先级。

关键知识点
括号优先级最高

(1+2)*3 先算括号内，结果为 9；1+2*3 先算乘法，结果为 7

算术 > 比较 > 逻辑

优先级：算术运算符 > 比较运算符 > 逻辑运算符 > 赋值运算符

结合性

多数运算符从左向右结合；=、?= 等从右向左结合

记忆口诀

括号最高，逗号最低；算术 > 比较 > 逻辑 > 赋值。有疑问时加括号

动手练练
  • 测试 alert(true || false && false) — && 优先于 ||
  • 添加括号改变优先级：alert((true || false) && false)
  • 计算 var r = 2 + 3 * 4 > 10 && true; alert(r)，逐步分析优先级
挑战练习
  • 分析 var a=5; var b=10; alert(a < b && a + 5 >= b)，逐步写出计算过程
  • 不依赖括号完成表达式 1+2*3==7 || 4*2==6 && 5-3==2，验证与预期是否一致
HBuilderX 开发技巧
  • 运算符优先级不需要死记硬背。在 HBuilderX 中写代码时，如果不确定优先级，加括号是最安全的做法——既清晰又不会出错。

双向判断语句

实训目标：演示 if...else 语句——条件成立执行 if 块，不成立则执行 else 块。

关键知识点
if...else 语法

if(条件){ 语句1 } else{ 语句2 }，二选一执行

else 分支

当 if 条件为 false 时，执行 else 块内的语句

执行流程

true → 执行 if 块；false → 执行 else 块；之后都执行后续代码

  • 添加 else if 分支：else if(num1==num2){ alert('相等'); }

挑战练习
  • 用 prompt() 获取成绩（0-100），用 if...else 实现及格/不及格判断并给出不同提示
  • 实现商品打折计算：var price=100; if(price>=200){ alert(price*0.8); }else{ alert(price); }
HBuilderX 开发技巧
  • 在 HBuilderX 中，选中代码块后按 Ctrl+Shift+F 可以格式化代码，自动对齐 if...else 的缩进，使逻辑结构更清晰。

多向判断语句

实训目标：演示 if...else if...else if 语句——多个条件依次判断，匹配则执行对应语句。

关键知识点
if...else if 语法

依次判断各条件，匹配成功则执行对应块并跳出整个结构

多向判断适合范围判断；switch 适合变量等于固定值的场景

  • 在最后添加 else 分支：else{ alert('无此奖品'); }

  • 添加更多车型选项（轿车、SUV、卡车），用 if...else if 实现完整的奖品系统
  • 实现成绩等级系统：A(90-100)、B(80-89)、C(70-79)、D(60-69)、F(<60)，用 score=prompt() 获取分数
HBuilderX 开发技巧

switch条件语句

实训目标：演示 switch 多分支语句——根据变量值匹配不同的 case，注意 break 防止穿透。

关键知识点
switch 语法

switch(表达式){ case 值: 语句; break; default: 语句; }

case 匹配

使用 === 严格比较，类型和值都必须相等才匹配

break 防止穿透

忘记写 break 会导致"穿透"——继续执行后续 case，即使条件不匹配

default 默认分支

所有 case 都不匹配时执行，相当于 if...else if 中的 else

动手练练
  • 修改 name 为"小明"，观察 case 匹配效果
  • 删除某个 case 的 break，观察"穿透"现象——后续 case 也会被执行
  • 用 switch 实现星期判断：var day=new Date().getDay(); switch(day){ case 0: alert("周日"); break; ... }
挑战练习
  • 添加更多名次（4-10名），给每个名次设置不同的奖品，并测试缺少 break 时的穿透效果
  • 用 switch 实现简易计算器：根据运算符变量（+、-、*、/）对两个数执行对应运算并输出结果
HBuilderX 开发技巧
  • switch 语句最常见的 Bug 就是忘记写 break 导致穿透。在 HBuilderX 中，建议每写一个 case 就立即写好 break，再填充 case 体，避免遗漏。
