任务 29

翻牌动画

运用 CSS3 变形属性（transform）实现 2D/3D 变形效果，制作鼠标悬浮翻牌动画。

70分钟 8个示例

💡 本节核心目标

CSS3 变形（transform）是网页动画的核心能力之一。它能在不改变文档流布局的前提下，对元素进行平移、缩放、旋转、倾斜等视觉变换。与通过 margin/left/top 移动不同，transform 变形不会影响其他元素的位置，且由 GPU 加速渲染，性能更优。本任务将带你掌握 transform 的完整用法，并制作一个翻牌动画。

8-8

translate() 平移

实训目标：掌握 translate() 平移函数的用法，理解平移与 position: relative 移动的区别。

关键知识点
translate(x, y)

将元素沿 X 轴移动 x，沿 Y 轴移动 y。相对于元素自身位置进行。

translateX(tx)

仅沿 X 轴水平移动。正值向右，负值向左。

translateY(ty)

仅沿 Y 轴垂直移动。正值向下，负值向上。

百分比单位

百分比相对于元素自身的宽高（非父元素）。translate(50%, 50%) 向右/下移动自身尺寸的一半。

单位不可省略

translate(100) 无效！必须写单位：translate(100px) 或 translate(50%)。

居中技巧

position: absolute; left: 50%; top: 50%; transform: translate(-50%,-50%); 是实现元素居中的经典方案。

动手练练
  • 将 translate(100px, 30px) 改为 translateX(100px)，观察效果。
  • 改为 translate(50%, 0)，观察移动距离与元素自身宽度的关系。
  • 尝试用 translate 实现一个元素在父容器中水平垂直居中（提示：需配合 position: absolute）。
8-9

scale() 缩放

实训目标：掌握 scale() 缩放函数的用法，理解缩放中心点（transform-origin）的影响。

关键知识点
scale(x, y)

x 为水平缩放倍数，y 为垂直缩放倍数。大于1放大，0~1缩小，负数镜像+缩放。

scaleX(sx) / scaleY(sy)

仅水平/垂直缩放。省略第二参数时默认等于第一参数（等比缩放）。

scale(0)

元素缩为不可见（常用于消失动画）。等价于 scale(0, 0)。

无需单位

缩放值是倍数，直接写数字，不能加单位！scale(2) ✅，scale(2px) ❌。

常见应用

悬浮放大图片 img:hover { transform: scale(1.1); }；点击缩小反馈 :active { transform: scale(0.95); }。

负数效果

scale(-1, 1) 水平镜像翻转；scale(-1, -1) 同时水平+垂直翻转。

动手练练
  • 将 scale(2, 3) 改为 scale(0.5)，观察缩小效果。
  • 改为 scaleX(-1)，观察水平镜像效果。
  • 为原始元素添加 :hover { transform: scale(1.2); }，观察悬浮放大效果。
8-10

skew() 倾斜

实训目标：掌握 skew() 倾斜函数的用法，理解倾斜角度的方向规律。

关键知识点
skew(x, y)

沿 X 轴倾斜 x 度，沿 Y 轴倾斜 y 度。会改变元素形状，文字内容也随之倾斜。

skewX(angle)

仅沿 X 轴倾斜（顶边向右/左倾斜）。正值→顶边向右倾斜。

skewY(angle)

仅沿 Y 轴倾斜（左侧向上/下倾斜）。正值→左边向下倾斜。

单位 deg

倾斜角度必须使用 deg 单位。可正可负。

斜角标签效果

容器 skewX(-15deg) + 内部文字 skewX(15deg) 反向倾斜，可制作斜角促销标签。

省略第二参数

只写一个值时，表示 skewX(value)，Y 轴不倾斜（等同于 0）。

动手练练
  • 将 skew(30deg, 10deg) 改为 skewX(30deg)，观察效果。
  • 改为 skewY(20deg)，观察左侧倾斜方向。
  • 尝试用 skewX(-15deg) 制作一个斜角标签，内部文字保持水平（提示：内部元素反向 skewX(15deg)）。
8-11

transform-origin 更改变换中心点

实训目标：掌握 transform-origin 属性的用法，理解变换中心点对旋转/缩放效果的影响。

关键知识点
默认变换中心点

元素中心（50% 50%）。旋转、缩放都围绕这个点进行。

transform-origin: x y

修改变换基准点。x/y 可用 px、%、关键词（left/center/right/top/bottom）。

z 轴参数

仅用于 3D 变形，只能用 px 长度值，不能使用百分比。

关键词映射

top left = 0% 0%；center center = 50% 50%；bottom right = 100% 100%。

多变形叠加

多个变形函数用空格隔开：transform: rotate(45deg) scale(1.2);。

变形顺序影响结果

rotate(45deg) translate(100px) 与 translate(100px) rotate(45deg) 结果不同！

动手练练
  • 将 transform-origin: 20% 40% 改为 transform-origin: left top，观察旋转中心变化。
  • 改为 transform-origin: 100% 100%，观察旋转中心是否在右下角。
  • 设计一个时钟指针效果：指针围绕底部端点旋转（提示：transform-origin: 50% 100%）。
8-12

rotateX() 围绕 X 轴旋转

实训目标：掌握 rotateX()、rotateY()、rotateZ() 三轴旋转的用法，理解 2D 与 3D 旋转的区别。

关键知识点
rotate(angle)

2D 旋转，围绕 Z 轴旋转（平面旋转）。正值顺时针，负值逆时针。

rotateX(a)

围绕水平 X 轴旋转。正值→顶部向屏幕内翻转。需配合 perspective 才有透视感。

rotateY(a)

围绕垂直 Y 轴旋转。正值→右侧向屏幕内翻转。翻牌动画的核心属性。

rotateZ(a)

围绕 Z 轴旋转，等同于 2D rotate()，但属于 3D 变形语法。

rotate3d(x,y,z,angle)

自定义旋转轴。x/y/z 定义轴向量（0 或 1），angle 为旋转角度。

透视感

2D 变形时 rotateX/Y 没有透视效果，必须配合 perspective 属性才会有 3D 视觉。

动手练练
  • 将 rotateX(60deg) 改为 rotateY(60deg)，观察 Y 轴旋转效果。
  • 改为 rotate(45deg)（2D 旋转），对比与 rotateZ(45deg) 的效果是否相同。
  • 在父元素添加 perspective: 400px，再观察 rotateX(60deg) 的透视效果。
8-13

perspective 透视效果

实训目标：掌握 perspective 属性和 perspective() 函数的区别，理解 3D 透视的原理。

关键知识点
perspective（属性）

设置在父元素上，为所有子元素的 3D 变形提供统一的透视距离。值越小透视感越强。

perspective() 函数

写在当前元素的 transform 中：transform: perspective(500px) rotateX(45deg);。只影响当前元素。

transform-style

preserve-3d：子元素在 3D 空间中保留位置；flat（默认）：子元素展平到父元素平面。

backface-visibility

hidden：元素背面朝向屏幕时不可见（翻牌效果的核心）；visible（默认）：背面可见。

推荐透视值

通常 500px~1000px 之间效果自然；100px~300px 透视感强烈（近大远小感强）。

3D 空间三属性

① perspective（父元素）② transform-style: preserve-3d（父元素）③ transform（子元素）。缺一不可！

动手练练
  • 将 perspective: 250px 改为 800px，观察透视感是否变弱。
  • 改为 100px，观察透视感是否变强（近大远小）。
  • 去掉 perspective 属性，观察 rotateX(60deg) 是否变成 2D 压缩效果。
8-14

3D 综合变形

实训目标：综合运用 translateZ()、rotateX()、transform-style: preserve-3d 实现 3D 空间布局。

关键知识点
translate3d(x,y,z)

3D 位移（同时设置三轴）。translateZ(z) 沿 Z 轴移动，正值靠近屏幕。

scale3d(x,y,z)

3D 缩放。scaleZ(z) 需配合 perspective 才有视觉效果。

rotate3d(x,y,z,angle)

3D 旋转。x/y/z 定义旋转轴向量，angle 为角度。如 rotate3d(1,1,0,45deg)。

变形顺序从右到左

rotateX(90deg) translateZ(100px)：先沿 Z 轴移动，再旋转 X 轴（因为从右到左应用）。

Z 轴方向

Z+ 向用户方向（靠近屏幕）；Z- 垂直屏幕方向（远离屏幕）。

3D 旋转木马原理

每个子元素先 rotateY(n*60deg) 再 translateZ(300px)，父元素动态更新 rotateY 角度。

动手练练
  • 将 translateZ(100px) 改为 translateZ(-100px)，观察元素是否"远离"屏幕。
  • 在 .wrap 中添加 rotateY(45deg) 到 :hover 中，观察 Y 轴 3D 旋转效果。
  • 尝试制作一个 3D 立方体：6 个子元素分别旋转并沿 Z 轴移出，组合成一个正方体。
8-15

翻牌动画结构

实训目标：综合运用本案例所有知识点，制作一个完整的鼠标悬浮翻牌动画效果。

翻牌动画实现步骤总结
步骤1：容器透视

父元素设置 perspective: 400px，为 3D 旋转提供透视距离。

步骤2：图片重叠

两张图片 position: absolute 重叠在同一位置。

步骤3：隐藏背面

两张图片都设置 backface-visibility: hidden，背面朝向屏幕时不可见。

步骤4：正面初始隐藏

正面图片初始 rotateY(180deg)，背面朝向屏幕，配合 backface-visibility: hidden 不可见。

步骤5：添加过渡

transition: all 1s linear 让翻转过程平滑过渡。

步骤6/7：hover 触发翻转

悬浮时正面从 0°→-180°（隐藏），背面从 180°→0°（显现）。

动手练练
  • 将 perspective: 400px 改为 800px，观察透视感变化对翻牌效果的影响。
  • 将 transition: all 1s linear 改为 ease-in-out，观察速度曲线变化。
  • 尝试制作"双面卡片"效果：正面显示头像，背面显示个人简介（用两个 div 替代 img）。
