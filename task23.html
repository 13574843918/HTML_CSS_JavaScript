任务二十三

商品专栏

掌握三种清除浮动的方法，解决父元素高度塌陷问题，制作整齐的商品专栏布局。

预计学习时长：60分钟
clear / overflow / ::after

学习目标

  • 理解浮动造成父元素高度塌陷的原因
  • 掌握空标签清除浮动方法（了解，不推荐）
  • 掌握 overflow: hidden 清除浮动方法（推荐）
  • 掌握 ::after 伪元素清除浮动方法（最佳实践）
  • 能够综合运用清除浮动完成商品专栏布局
⚡ HBuilderX 使用技巧 · 本节专属 clear & 清除浮动
🧹
overflow:hidden 快捷

输入 ov:h 按 Tab，自动补全 overflow: hidden;，最常用的清除浮动方式。

🎭
::after 伪元素

输入 :after 按 Tab，生成伪元素选择器模板，用于最佳实践清除浮动写法。

🔎
开发者工具查高度

按 F12 → 选中父元素，在盒模型面板可直观看到高度是否塌陷为 0。

📋
clear:both 简写

输入 cl:b 按 Tab，自动补全 clear: both;，同时清除左右浮动影响。

📐
visibility:hidden

输入 v:h 按 Tab，补全 visibility: hidden;，伪元素清除浮动时需要此属性隐藏内容。

⚠️
content: "" 必须有

::after 伪元素必须设置 content: "" 属性，否则伪元素不会生成，清除浮动失效。

01

example 7-3：浮动对父元素的影响（高度塌陷）

实训目标：观察当子元素全部浮动后，父元素高度变为 0（塌陷）的问题现象，理解产生原因，为后续学习清除浮动方法做铺垫。

关键知识点
父元素高度塌陷

子元素全部浮动时，父元素感知不到子元素高度，height 变为 0

影响后续布局

父元素塌陷后，紧跟其后的元素会向上填充，导致布局错乱

解决方案

需要使用清除浮动的方法，让父元素"感知"到子元素

动手练练
  • 给 .father 添加 height: 100px;，观察塌陷问题消失，但这是"硬编码"方式
  • 删除所有 float: left;，观察父元素高度自动撑开，说明浮动导致了塌陷
02

example 7-4：方法一 — 空标签清除浮动（了解）

实训目标：了解在浮动元素后方添加空标签并设置 clear:both 来清除浮动的方法。注意：此方法会污染 HTML 结构，实际工作中不推荐使用。

关键知识点
clear: both

清除左右两侧浮动对当前元素的影响

clear: left/right

清除指定方向的浮动影响

缺点

在 HTML 中增加无语义的空标签，结构不够纯净

动手练练
  • 删除 <div class="clearfix"></div>，观察父元素重新塌陷
  • 将 clear: both 改为 clear: left，观察是否仍然生效（因为全是左浮动）
03

example 7-5：方法二 — overflow:hidden 清除浮动（推荐）

实训目标：掌握在父元素上添加 overflow: hidden 来清除浮动的方法。此方法无需添加额外 HTML 标签，是工作中常用的清除浮动方式之一。

关键知识点
overflow: hidden

写在父元素上，触发 BFC 机制，让父元素包裹浮动子元素

BFC 块格式化上下文

overflow:hidden 触发 BFC，BFC 会将内部浮动元素纳入高度计算

优点

无需添加额外标签，CSS 写在父元素上即可，简洁高效

注意

如有子元素溢出显示需求（如下拉菜单），此方法会裁剪溢出内容

动手练练
  • 删除 overflow: hidden;，观察父元素再次塌陷，验证该属性的作用
  • 将 overflow: hidden 改为 overflow: auto，观察是否也能清除浮动
挑战练习
  • 在 box03 后面添加一个宽度 200px、超出父元素的绝对定位元素，看 overflow:hidden 是否会把它裁掉
04

example 7-6：方法三 — ::after 伪元素清除浮动（最佳实践）

实训目标：掌握用 CSS 伪元素 ::after 在父元素末尾自动插入清除浮动标签的方法，这是业界公认的最佳实践，适用于各类浏览器。

关键知识点
::after 伪元素

CSS 自动在元素末尾插入虚拟内容，相当于自动添加一个清除浮动的空标签

content: ""

必须设置，否则伪元素不会生成（哪怕值为空字符串）

height: 0

伪元素高度设为 0，不影响父元素布局，仅起清除浮动作用

visibility: hidden

即使有内容也不显示，确保清除浮动元素不可见

动手练练
  • 删除 content: ""; 这行，观察伪元素失效，父元素再次塌陷
  • 将 height: 0 改为 height: 20px，观察父元素高度多出 20px
  • 将 visibility: hidden 改为 visibility: visible，观察伪元素内容是否出现
挑战练习
  • 将 ::after 改为 ::before，观察是否还能清除浮动（思考为什么不同）
05

example 7-7：商品专栏（综合案例）

实训目标：综合运用浮动和清除浮动，完成一个商品展示专栏页面。图片左浮动并排展示，说明文字使用 clear: left 排在图片下方，实现整洁的图文分区布局。

关键知识点
clear: left

不允许左侧有浮动元素，让段落排在所有左浮动图片之后

图文混排布局

图片浮动横向排列，文字清除浮动后在图片下方竖向排列

margin-bottom

浮动元素间的间距用 margin 控制，不影响清除浮动逻辑

动手练练
  • 删除段落 p 的 clear: left;，观察文字和图片如何混排在一起
  • 修改 .box 的 width 和 height，让三张图片能一行排完
  • 给 .all 添加 overflow: hidden;，看是否能解决父元素高度问题
拓展练习 · 图片新闻列表

制作一个图文混排的新闻列表，每条新闻左侧缩略图浮动，右侧显示标题和摘要，列表条目间用分隔线，使用 ::after 伪元素清除每条新闻内部的浮动。

  • 任务一：取消 .news-item::after 样式的注释，观察每条新闻的高度是否正确包裹缩略图
  • 任务二：修改 .thumb 的 float: left 为 float: right，让缩略图显示在右侧
  • 任务三：给 .news-item:last-child 添加 border-bottom: none，去掉最后一条分隔线
  • 任务四（挑战）：添加 hover 效果，鼠标悬浮新闻条目时背景变为浅灰色
