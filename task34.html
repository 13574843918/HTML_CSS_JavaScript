while循环语句

实训目标：掌握 while 循环的基本用法——当条件为 true 时重复执行循环体，注意更新循环变量避免死循环。

关键知识点
while 语法

while(条件){ 循环体 }，先判断后执行，条件为true时重复执行

循环变量

必须在循环体内更新，使条件趋向false，否则造成死循环

循环条件

每次循环开始前判断，为false时退出循环

死循环警告

忘记写 a++ 会导致浏览器卡死，测试前建议加安全退出条件

执行流程

初始化 → 判断条件 → true执行循环体 → 更新变量 → 再判断

最少执行次数

while 循环最少执行 0 次（条件一开始就为false时）

动手练练
  • 修改循环条件为 a < 10，观察输出次数的变化
  • 删除 a++，观察浏览器是否卡死（死循环）——注意先保存其他工作！
  • 用 while 计算 1+2+3+...+100 的和：var sum=0, i=1; while(i<=100){ sum+=i; i++; }
  • 用 while 倒序输出 5~1：修改初始值和条件
挑战练习
  • 用 while 循环输出 1~20 中所有偶数，并计算偶数的个数
  • 用 while 实现猜数字游戏：随机生成 1~100 的数，循环让用户输入直到猜对
HBuilderX 开发技巧
  • 如果不小心写了死循环导致浏览器卡死，可以按 Esc 键或关闭浏览器标签页来终止
  • 在测试循环前，建议先在循环体中加入 if(a>100) break; 作为安全退出机制

do...while循环语句

实训目标：掌握 do...while 循环——先执行一次循环体，再判断条件，至少执行一次。

关键知识点
do...while 语法

do{ 循环体 }while(条件); 注意末尾有分号

先执行后判断

无论条件是否满足，至少执行一次循环体

末尾分号

while(条件) 后面的分号不能省略，这是常见语法错误

与 while 对比

while 可能执行0次，do...while 至少执行1次

适用场景

至少需要执行一次的场景，如菜单显示后判断用户选择

执行流程

执行循环体 → 判断条件 → true继续 → false退出

动手练练
  • 修改 a=1，观察循环执行多次的效果
  • 将 do...while 改为 while，设置 a=100，观察 while 是否执行（不会）
  • 在 while(a < 10) 后去掉分号，观察语法错误
  • 用 do...while 实现菜单选择：先显示菜单，再判断用户选择是否有效
挑战练习
  • 用 do...while 实现输入验证：要求用户必须输入 1~5 之间的数字，否则重新输入
  • 对比 while 和 do...while：用两种循环分别实现"输出 1~10 的和"，分析区别
HBuilderX 开发技巧
  • do...while 末尾的 while(条件); —— 分号不能省略！这是常见的语法错误
  • HBuilderX 会在此处标记语法警告，注意查看编辑器左侧的提示标记

for循环语句

实训目标：掌握 for 循环的三部分结构（初始化、条件、更新），使用 for 循环计算 100 以内所有奇数的和。

关键知识点
for 三部分

for(初始化; 条件; 更新){ 循环体 }，三部分用分号分隔

初始化表达式

循环开始前执行1次，声明并初始化循环变量

循环条件

每次循环开始前判断，决定是否继续循环

操作表达式

每次循环体执行完后执行，更新循环变量

与 while 对比

循环次数已知时优先用for，次数未知时用while

i+=2

每次加2，实现只取奇数（1,3,5...99）

动手练练
  • 修改为计算偶数和：将 i=1 改为 i=0，i+=2 保持不变
  • 计算 1+2+3+...+100 的和：for(var i=1; i<=100; i++)
  • 输出 1~100 中所有能被 3 整除的数：if(i%3===0) document.write(i+"<br>")
  • 用 for 输出九九乘法表的前 5 行（需要嵌套循环）
挑战练习
  • 用 for 循环实现完整的九九乘法表输出（嵌套循环）
  • 用 for 循环找出 1~1000 中第一个能被 7 和 13 同时整除的数（配合 break）
HBuilderX 开发技巧
  • 在 HBuilderX 中，输入 for 后按 Tab 可快速生成循环模板
  • 注意 for(var i=0; i<arr.length; i++) 中的三个部分用分号分隔，不是逗号

break语句

实训目标：掌握 break 语句——在循环中满足条件时立即跳出整个循环，不再执行后续迭代。

关键知识点
break 作用

立即结束整个循环，执行循环后面的语句

在 switch 中

跳出当前 case，防止穿透

在循环中

只跳出当前所在的那一层循环，不会影响外层循环

与 continue 对比

break 结束整个循环；continue 只跳过本次循环的剩余语句

动手练练
  • 修改条件为 if(sum>50)break，观察跳出时的累加结果
  • 在嵌套循环中测试 break：外层循环是否被跳出？（不会，只跳出内层）
  • 查找数组中第一个大于 5 的元素：var arr=[1,3,7,2,9]; for(...){ if(arr[i]>5){ alert(arr[i]); break; } }
挑战练习
  • 用 for + break 在数组 [3,7,2,9,1,5,8] 中找到第一个大于 6 的数，输出其索引和值
  • 用嵌套循环 + break 实现质数判断：对 2~50 的每个数判断是否为质数
HBuilderX 开发技巧
  • break 常用于"找到就停"的场景——在数组中查找元素、找到满足条件的值后立即退出
  • 避免不必要的迭代，提高程序效率

continue语句

实训目标：掌握 continue 语句——跳过本次循环的剩余语句，直接进入下一次循环迭代。

关键知识点
continue 作用

跳过本次循环的剩余语句，直接进入下一次循环的条件判断

与 break 对比

break 结束整个循环；continue 只跳过本轮，继续下一轮

形象比喻

break 是"紧急出口"——直接离开；continue 是"跳过这一轮"——继续下一轮

执行流程

遇到 continue → 跳过后续语句 → 回到循环条件判断 → 继续或退出

动手练练
  • 修改跳过条件为 if(i%2===0) continue，只输出奇数
  • 将 continue 改为 break，观察区别——break 直接结束整个循环
  • 输出 1~50 中所有不能被 7 整除的数：if(i%7===0) continue;
挑战练习
  • 用 continue 输出 1~100 中所有个位不为 3 且不能被 3 整除的数
  • 对比实验：将同一个程序中的 continue 替换为 break，记录输出的差异并分析原因
HBuilderX 开发技巧
  • continue 的形象比喻是"跳过这一轮，继续下一轮"，它不会结束循环，只是跳过当前迭代的剩余代码
  • 在 HBuilderX 中调试时，可以在 continue 前后设置断点，观察变量的变化

关键知识点
for 循环遍历

用 for 循环遍历所有 Tab 头部和内容元素，统一绑定事件

onmouseover 事件

鼠标移入 Tab 头部时触发，显示对应内容并暂停自动轮播

className 操作

通过添加/移除 "current" 类名控制 Tab 头部和内容的显示状态

setInterval 自动轮播

每 5 秒自动切换到下一个 Tab，clearInterval 暂停轮播

闭包特性

内部函数 autoChange 访问外部变量 current_index，实现状态共享

数组基础

var arr = []; arr.length; arr[i]; arr.push(); arr.pop()
