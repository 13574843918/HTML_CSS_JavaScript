案例实现：用户登录界面

实训目标：综合运用 form、input 标签与 CSS 样式，制作用户登录界面。掌握表单容器布局与输入控件的美化方法。

关键知识点
<form>

表单容器，action 指定提交地址，method 指定提交方式

method="get"

数据显示在地址栏，有数据量限制，保密性差

method="post"

分段传输，无数据量限制，保密性好（推荐）

display: block

input 转为块元素后，可用 margin: auto 居中

type="text"

单行文本框，value 属性设置默认文字

type="button"

普通按钮，常配合 JS 使用，value 为显示文字

动手练练
  • 将第二个 input 的 type="text" 改为 type="password"，观察输入框变为密码框
  • 在登录按钮下方再添加一个 type="reset" 的重置按钮，value 设为"清空"
  • 修改 .list 的 background 颜色，体验不同深色背景效果
  • 给 .btn 添加 border-radius: 4px，让按钮有圆角效果

📋 提示词范本（可直接复制使用）
请用纯 HTML + CSS 帮我制作一个用户登录界面，要求如下：

【功能要求】
1. 包含手机号输入框（type="text"）
2. 包含密码输入框（type="password"）
3. 包含"登录"按钮（type="submit"）
4. 包含"注册账号"文字链接
5. 使用 <form> 标签包裹，method="post"

【样式要求】
1. 整体深色风格，背景色 #0f172a
2. 表单卡片居中显示，宽度 400px，带圆角和阴影
3. 输入框宽度撑满卡片，高度 44px，深色背景，白色文字
4. 登录按钮宽度撑满，蓝色背景 #2563eb，白色文字，圆角 8px
5. 所有元素之间有合适的间距

【技术要求】
1. 只用 HTML + CSS，不需要 JavaScript
2. 代码结构清晰，含必要注释
3. 输出完整可运行的 HTML 文件代码

💡 提示词技巧：提示词越具体，AI 生成的代码质量越高。可以加上"参考 Apple 官网风格"或"参考微信登录页"等风格描述，让效果更贴近需求。
