9-01

prompt() 对话框 — 身份验证

实训目标：掌握 prompt() 对话框的使用方法，了解 <script> 标签嵌入 JavaScript 代码的基本方式。

关键知识点
alert()

警告对话框，仅显示提示信息，返回 undefined

prompt()

输入对话框，获取用户输入，返回字符串或 null

confirm()

确认对话框，用户选择确定/取消，返回 true/false

<script>

嵌入式引入 JS，type 属性声明脚本类型

行内式

在 HTML 标签中直接写 JS，如 onclick 属性

外链式

通过 src 引入外部 .js 文件，推荐方式

动手练练
  • 将 prompt() 替换为 alert('欢迎访问本网站！')，观察警告对话框的效果
  • 将 prompt() 替换为 confirm('确定要退出吗？')，观察确认对话框的效果
  • 尝试用变量接收 prompt 的返回值：var name = prompt('请输入姓名','例如张三'); alert('你好，' + name);
挑战练习
  • 将 <script> 标签从 <head> 移到 </body> 前面，观察执行时机的变化
  • 综合运用三种对话框：先用 confirm() 确认，再用 prompt() 输入，最后用 alert() 显示结果
HBuilderX 小技巧
  • 输入 script 后按 Tab 可快速生成 <script type="text/javascript"></script> 标签
  • 使用 Ctrl+R 可快速在浏览器中预览页面效果
  • JavaScript 语法错误会在控制台（F12）中显示红色提示，遇到问题先查看控制台
拓展练习 · 简易身份验证系统

综合运用本节学习的 alert()、prompt()、confirm() 三种对话框，制作一个简易身份验证系统。通过获取用户输入、确认操作、显示结果，实现完整的交互流程。

  • 任务一：使用 confirm() 弹出确认对话框，获取用户选择
  • 任务二：确认后使用 prompt() 获取用户名输入
  • 任务三：用 alert() 显示"欢迎你，XXX！"的个性化欢迎信息
  • 任务四（挑战）：添加密码验证，用户输入密码后判断是否正确再显示欢迎信息
