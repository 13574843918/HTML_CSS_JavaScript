定义函数

实训目标：学习使用 function 关键字定义函数并调用，理解函数参数和返回值的概念。

关键知识点
function 关键字

声明函数的关键字，后跟函数名和参数列表

函数参数

外部传入的数据，多个用逗号分隔，调用时按顺序传入

return 返回值

返回结果并终止函数执行，无 return 时返回 undefined

函数调用

函数定义后不会自动执行，必须显式调用函数名()

匿名函数

没有函数名的函数，常赋值给变量或作为事件处理函数

变量作用域

函数内声明的变量为局部变量，只在函数体内可访问

  • 将 <script> 移到 </body> 前，观察执行时机变化
  • 尝试将函数赋值给变量：var greet = function(){ alert("Hi!"); }; greet();
挑战练习
  • 尝试将函数赋值给变量：var sayHi = function(name){ return "你好, " + name; }; 并调用
  • 使用箭头函数重写：const hello = () => alert("Hello!");

9-04

变量的作用域

实训目标：理解全局变量与局部变量的区别，掌握 var/let/const 的声明差异和作用域规则。

关键知识点
局部变量

在函数体内用 var/let/const 声明的变量，只在函数内可访问

全局变量

在所有函数外声明的变量，整个程序运行期间都可访问

var 关键字

函数作用域，有变量提升，可重复声明，ES6 前唯一声明方式

let 关键字

块级作用域，有暂时性死区，不可重复声明，ES6 推荐

const 关键字

块级作用域，声明时必须赋值，基本类型不可修改

变量提升(Hoisting)

var 声明的变量提升到作用域顶部（值为 undefined）

动手练练
  • 将 var a="欢迎来到" 移到所有函数外面（变为全局变量），观察 send2() 是否能正常执行
  • 用 let 替换 var 声明变量，观察行为差异
  • 在 send1() 内尝试 alert(c)，验证局部变量不可跨函数访问
  • 测试变量提升：在 var a = "hello" 之前添加 alert(a)，观察输出结果
挑战练习
  • 测试 let/const 的块级作用域：在 if 块内用 let 声明变量，块外访问会怎样？
  • 变量提升实验：分别在 var 和 let 声明前调用变量，对比 undefined 和 ReferenceError
HBuilderX 开发技巧
  • 按 F12 打开浏览器控制台，可以查看 JavaScript 运行时的错误信息
  • 变量未定义时会报 ReferenceError，这是调试作用域问题的重要工具
9-05

事件和事件调用

实训目标：学习为按钮绑定 onclick 事件，理解事件绑定的三种方式及其优缺点。

关键知识点
onclick 事件

鼠标单击事件，最常用。绑定方式：DOM 属性或 addEventListener

addEventListener()

现代事件绑定方式，可为同一事件绑定多个处理函数

onmouseover

鼠标移入元素时触发，会发生事件冒泡

onmouseout

鼠标移出元素时触发，配合 onmouseover 实现悬浮效果

事件冒泡

事件从触发元素逐层向上传播到父元素（默认行为）

window.onload

页面所有资源加载完成后触发，确保 DOM 元素已存在

动手练练
  • 将匿名函数改为具名函数：function showMessage(){ alert("轻松学习JavaScript事件"); } 然后 btn.onclick = showMessage;
  • 使用 addEventListener 绑定事件：btn.addEventListener('click', function(){ alert("Hi!"); });
  • 添加双击事件：btn.ondblclick = function(){ alert("双击触发"); }
  • 绑定多个事件：用 addEventListener 绑定两个不同的 click 处理函数，观察是否都能触发
挑战练习
  • 使用 addEventListener 为按钮绑定 click 和 dblclick 两个事件
  • 创建父子两层 div，分别在两层绑定 click 事件，观察事件冒泡现象并尝试 event.stopPropagation() 阻止冒泡
HBuilderX 开发技巧
  • 使用 Ctrl+R 运行页面后，可在浏览器中右键选择"检查"打开开发者工具
  • 在 Elements 面板中选中元素，可以在 Event Listeners 标签页查看该元素绑定的所有事件
9-06

商城下拉菜单

实训目标：综合运用 onmouseover/onmouseout 事件和 display 属性，实现商城导航栏下拉菜单效果。

关键知识点
display:none/block

控制元素显示与隐藏，none 不占空间，block 显示为块级元素

onmouseover

鼠标移入触发，用于显示下拉菜单

onmouseout

鼠标移出触发，用于隐藏下拉菜单

onmouseenter

与 onmouseover 类似但不冒泡，推荐用于下拉菜单

style.display

通过 JS 直接修改元素的内联 display 样式

综合应用思路

①获取触发元素 ②获取目标元素 ③绑定 onmouseover 显示 ④绑定 onmouseout 隐藏

动手练练
  • 为"服装鞋帽"也添加下拉菜单效果，添加对应的子菜单 HTML 和 JS 代码
  • 将 onmouseover/onmouseout 替换为 onmouseenter/onmouseleave，观察是否消除了闪烁问题
  • 修改下拉菜单的背景色和文字样式，美化菜单外观
  • 添加 CSS 过渡效果：#dis{transition: opacity 0.3s;} 配合 opacity 实现淡入淡出
挑战练习
  • 添加 CSS 过渡效果 transition: all 0.3s ease，让下拉菜单有平滑的动画
  • 用 opacity 和 visibility 配合实现淡入淡出效果，而非简单的 display 切换
HBuilderX 开发技巧
  • 制作下拉菜单时，常见问题是鼠标移到子菜单时菜单会闪烁
  • 解决方法：确保子菜单紧贴父菜单（无间距），或使用 onmouseenter/onmouseleave 代替 onmouseover/onmouseout（前者不会冒泡）

  • 任务二：将 onmouseover/onmouseout 替换为 onmouseenter/onmouseleave，消除闪烁问题
  • 任务三：添加 CSS 过渡效果 transition: opacity 0.3s 实现淡入淡出
  • 任务四（挑战）：封装 function toggleMenu(menuId, subId) 函数，用循环为所有菜单统一绑定事件
