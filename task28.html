任务 28

导航栏悬浮特效

运用 CSS3 过渡属性（transition）制作鼠标悬浮时的平滑动画效果。

50分钟 3个示例

💡 本节核心目标

CSS3 过渡（transition）是网页动画的基础。它能在 CSS 属性值发生变化时，自动创建平滑的过渡效果，而不需要 JavaScript。在实际开发中，过渡最常配合 :hover、:focus 等伪类使用，制作按钮变色、菜单展开、图片放大等交互效果。本任务将带你掌握 transition 的完整用法。

8-5

transition-property 与 transition-duration

实训目标：掌握 transition-property 和 transition-duration 两个核心子属性，理解过渡的触发条件。

关键知识点
transition-property

指定哪个 CSS 属性应用过渡效果。all 表示所有可动画属性，none 表示无过渡效果。

transition-duration

过渡完成所需时间（s 或 ms）。必须设置，否则默认值为 0，过渡不可见。

可过渡的属性

只有可计算中间值的属性才能过渡：width、height、color、opacity、transform 等。

不可过渡的属性

display（none↔block 是瞬间切换）、position、float 等无法计算中间值。

触发条件

过渡在 CSS 属性值发生变化时自动触发，常见触发方式：:hover、:focus、:active、JS 修改 class。

双向过渡

过渡写在元素本身（而非 :hover）上时，鼠标移入和移出都会触发过渡效果。

动手练练
  • 将 transition-property: border-radius; 改为 transition-property: all;，观察鼠标悬浮时哪些属性会过渡。
  • 将 transition-duration: 5s; 改为 5000ms，观察效果是否相同。
  • 尝试添加 transition-property: width; 和 width: 400px; 到 :hover 中，观察宽度是否会过渡。
8-6

transition-timing-function 与 transition-delay

实训目标：掌握过渡速度曲线（transition-timing-function）和延迟（transition-delay）的用法，理解贝塞尔曲线的含义。

关键知识点
ease（默认）

慢→快→慢。相当于 cubic-bezier(0.25, 0.1, 0.25, 1.0)。最常用。

linear

匀速，从头到尾速度相同。适合进度条、加载动画。

ease-in

慢启动，逐渐加速（淡入效果）。适合元素入场动画。

ease-out

慢结束，逐渐减速（淡出效果）。适合元素出场动画。

ease-in-out

慢→快→慢，比 ease 更平滑对称。适合通用平滑过渡。

cubic-bezier(n,n,n,n)

自定义贝塞尔曲线，4个参数值范围 0~1。可用 cubic-bezier.com 可视化调节。

steps(n, start|end)

分步过渡，分 n 步完成。常用于打字机效果、逐帧动画。

transition-delay

延迟开始的时间（s 或 ms）。默认 0。可用于制作交错动画（staggered animation）效果。

动手练练
  • 将 transition-timing-function 分别改为 linear、ease-in、ease-out，观察速度变化。
  • 将 transition-delay 改为 2s，观察延迟效果。
  • 尝试 transition-timing-function: cubic-bezier(0.68, -0.55, 0.265, 1.55);，观察弹性效果。
🔥 挑战练习
  • → 制作一个导航菜单，5 个菜单项依次出现（交错动画）：给每个 li:nth-child(n) 设置不同的 transition-delay 值。
8-7

transition 简写属性

实训目标：掌握 transition 简写属性的语法，理解参数顺序规则，能够用简写替代多个子属性。

关键知识点
简写语法

transition: property duration timing-function delay; 四个子属性按顺序书写，duration 必填。

参数顺序规则

第一个时间值 = duration（必填）；第二个时间值 = delay（可选）。

多属性过渡

用英文逗号分隔多组过渡值：transition: width 2s, background-color 1s;

all 关键字

transition: all 0.3s ease; 让所有可动画属性都过渡。方便但性能稍差，生产环境建议指定具体属性。

常见错误

忘记写 duration（默认 0，动画不可见）；把两个时间值的顺序写反。

最佳实践

只过渡需要平滑变化的属性（如 transform、opacity），避免过渡 width/height 等触发布局重排的属性。

动手练练
  • 将简写改为 transition: all 0.3s ease;，观察宽度和背景色是否都过渡了。
  • 将 transition: width 3s ease-in-out 1s; 中的 1s 去掉，观察延迟是否还生效。
  • 给自己设计一个导航栏，鼠标悬浮时背景色、文字颜色、阴影同时过渡，使用简写语法。
