## 案例17：简历表

### example01 — 创建基本表格

```html
<!doctype html>
<html>
<head>
    <meta charset="utf-8">
    <title>表格</title>
</head>
<body>
    <table border="1">
        <tr>
            <td>学生名称</td>
            <td>竞赛学科</td>
            <td>分数</td>
        </tr>
        <tr>
            <td>小明</td>
            <td>数学</td>
            <td>87</td>
        </tr>
        <tr>
            <td>小李</td>
            <td>英语</td>
            <td>86</td>
        </tr>
        <tr>
            <td>小萌</td>
            <td>物理</td>
            <td>72</td>
        </tr>
    </table>
</body>
</html>
```

**本节核心知识点：**
- `<table></table>`：定义表格的开始与结束
- `<tr></tr>`：定义表格中的一行，必须嵌套在 `<table>` 中
- `<td></td>`：定义表格中的单元格，必须嵌套在 `<tr>` 中
- `border` 属性：设置表格边框，默认值为 0（无边框）
- 默认情况下，表格宽高自适应内容，边框为 0

### example02 — `<tr>` 标签的属性

```html
<!doctype html>
<html>
<head>
    <meta charset="utf-8">
    <title>tr 标签的属性</title>
</head>
<body>
    <table border="1" width="400" height="240" align="center">
        <tr height="80" align="center" valign="top" bgcolor="#00CCFF">
            <td>姓名</td>
            <td>性别</td>
            <td>电话</td>
            <td>住址</td>
        </tr>
        <tr>
            <td>小王</td>
            <td>女</td>
            <td>11122233</td>
            <td>海淀区</td>
        </tr>
        <tr>
            <td>小李</td>
            <td>男</td>
            <td>55566677</td>
            <td>朝阳区</td>
        </tr>
        <tr>

            <td>男</td>
            <td>88899900</td>
            <td>西城区</td>
        </tr>
    </table>

```

**本节核心知识点：**

- `<tr>` 的常用属性：`height`、`align`（水平对齐）、`valign`（垂直对齐：top/middle/bottom）、`bgcolor`
- 注意：`<tr>` 无宽度属性 width，其宽度取决于 `<table>`
- 实际工作中推荐用 CSS 替代 HTML 属性

### example03 — 单元格合并（colspan / rowspan）

```html
<!doctype html>
<html>
<head>
    <meta charset="utf-8">
    <title>单元格的合并</title>
</head>
<body>
    <table border="1" width="400" height="240" align="center">
        <tr height="80" align="center" valign="top" bgcolor="#00CCFF">
            <td>姓名</td>
            <td>性别</td>
            <td>电话</td>
            <td>住址</td>
        </tr>
        <tr>
            <td>小王</td>
            <td>女</td>
            <td>11122233</td>
            <td rowspan="3">北京</td>  <!-- rowspan 设置单元格竖跨的行数 -->
        </tr>
        <tr>
            <td>小李</td>
            <td>男</td>
            <td>55566677</td>
            <!-- 删除了 <td>朝阳区</td> -->
        </tr>
        <tr>
            <td>小张</td>
            <td>男</td>
            <td>88899900</td>
            <!-- 删除了 <td>西城区</td> -->
        </tr>
    </table>
</body>
</html>
```

**本节核心知识点：**
- `<td>` 的 `colspan` 属性：设置单元格**横跨**的列数（水平合并）
- `<td>` 的 `rowspan` 属性：设置单元格**竖跨**的行数（垂直合并）
- 合并规则：合并哪些单元格就删除/注释它们，并在预留单元格中设置对应的 colspan 或 rowspan 值
- `<th>` 标签：表头单元格，文本默认**加粗居中**显示，用法与 `<td>` 相同

### example04 — 表格结构划分（thead / tfoot / tbody）

```html
<!doctype html>
<html>
<head>
    <meta charset="utf-8">
    <title>划分表格的结构</title>
</head>
<body>
    <table width="600" border="1" cellspacing="0" align="center">
        <caption>表格的名称</caption>  <!-- caption 定义表格的标题 -->
        <thead>  <!-- thead 定义表格的头部 -->
            <tr>
                <td colspan="3">网站的logo</td>
            </tr>
            <tr>
                <th><a href="#">首页</a></th>
                <th><a href="#">关于我们</a></th>
                <th><a href="#">联系我们</a></th>
            </tr>
        </thead>
        <tfoot>  <!-- tfoot 定义表格的页脚 -->
            <tr>
                <td colspan="3" align="center">底部基本企业信息&copy;【版权信息】</td>
            </tr>
        </tfoot>
        <tbody>  <!-- tbody 定义表格的主体 -->
            <tr height="150">
                <td>主体的左栏</td>
                <td>主体的中间</td>
                <td>主体的右侧</td>
            </tr>
            <tr height="150">
                <td>主体的左栏</td>
                <td>主体的中间</td>
                <td>主体的右侧</td>
            </tr>
        </tbody>
    </table>
</body>
</html>
```

**本节核心知识点：**
- `<caption>`：定义表格标题，位于 `<table>` 内部最顶端
- `<thead>`：定义表格头部
- `<tfoot>`：定义表格页脚（置于 tbody 之前，使浏览器可提前渲染页脚）
- `<tbody>`：定义表格主体
- 一个表格只能有一对 thead、一对 tfoot，但可以有多对 tbody
- 必须按 `<thead>` → `<tfoot>` → `<tbody>` 的顺序书写

### example05 — CSS 控制表格边框

```html
<!doctype html>
<html>

        }
    </style>
</head>
<body>

            <td>角色扮演</td>
            <td>3D武侠</td>
        </tr>
        <tr>
            <td>3</td>
            <td>龙之谷手游</td>
            <td>角色扮演</td>
            <td>3D格斗</td>
        </tr>
        <tr>
            <td>4</td>

            <td>5</td>

            <td>2D格斗</td>
        </tr>

```

**本节核心知识点：**
- 使用 CSS `border` 属性可以更灵活地控制表格边框颜色和粗细
- 只设置 `<table>` 的边框只显示外边框，需同时为 `th, td` 设置边框才有内边框
- `border-collapse: collapse`：使单元格边框**合并**，去掉单元格间隙，形成单线边框效果（常用）
- `border-collapse: separate`：边框分离（默认）
- 当 `border-collapse: collapse` 时，HTML 的 `cellspacing` 属性失效
- 行标签 `<tr>` 无 border 样式属性

### example06 — CSS 控制单元格边距

```html
<!doctype html>
<html>
<head>
    <meta charset="utf-8">
    <title>CSS 控制单元格边距</title>
    <style type="text/css">
        table {
            border: 1px solid #30F;  /* 设置 table 的边框 */
        }
        th, td {
            border: 1px solid #30F;  /* 为单元格单独设置边框 */
            padding: 50px;           /* 为单元格内容与边框设置内边距 */
            /* margin: 50px; */      /* 单元格的 margin 无效 */
        }
    </style>
</head>
<body>
    <table>
        <tr>
            <th>游戏名称</th>
            <th>类型</th>
            <th>特征</th>
        </tr>
        <tr>
            <th>王者荣耀</th>
            <td>策略战棋</td>
            <td>3D竞技</td>
        </tr>
        <tr>
            <th>天龙八部手游</th>
            <td>角色扮演</td>
            <td>3D武侠</td>
        </tr>
    </table>
</body>
</html>
```

**本节核心知识点：**
- 单元格内边距：对 `<th>` 和 `<td>` 应用 CSS `padding` 属性（等效于 HTML 的 `cellpadding`）
- 单元格**外边距** `margin` 对 `<th>` 和 `<td>` **无效**
- 要设置相邻单元格边框间距，只能使用 HTML 的 `cellspacing` 属性
- 行标签 `<tr>` 无 `padding` 和 `margin` 属性

### example07 — CSS 控制单元格宽高

```html
<!doctype html>
<html>
<head>
    <meta charset="utf-8">
    <title>CSS 控制单元格的宽高</title>
    <style type="text/css">
        table {
            border: 1px solid #30F;
            border-collapse: collapse;
        }
        th, td {
            border: 1px solid #30F;
        }
        .one { width: 100px; height: 80px; }   /* 定义"A房间"单元格的宽度与高度 */
        .two { height: 40px; }                  /* 定义"B房间"单元格的高度 */
        .three { width: 200px; }               /* 定义"C房间"单元格的宽度 */
    </style>
</head>
<body>
    <table>
        <tr>
            <td class="one">A房间</td>
            <td class="two">B房间</td>
        </tr>
        <tr>
            <td class="three">C房间</td>
            <td class="four">D房间</td>
        </tr>
    </table>
</body>
</html>
```

**本节核心知识点：**
- 同一行中的单元格高度不同时，**取最大高度值**（A/B 同行，B 设 40px，A 设 80px → 最终行高 80px）
- 同一列中的单元格宽度不同时，**取最大宽度值**（A/C 同列，C 设 200px → 整列宽度 200px）

## 案例18：用户登录界面

### example09 — 案例实现：用户登录界面

```html
<!doctype html>
<html>
<head>
    <meta charset="utf-8">
    <title>用户登录界面</title>
    <style type="text/css">
        /* 重置浏览器的默认样式 */
        body, form, input {
            margin: 0;
            padding: 0;
            border: none;
        }
        /* 整体控制表单 */
        .list {
            width: 500px;
            height: 280px;
            background: url(images/bg.png) no-repeat;
            margin: 50px auto;
            padding-top: 70px;
        }
        /* 控制 input 控件 */
        input {
            display: block;
            width: 290px;
            height: 34px;
            background-color: #11131f;
            border: 2px solid #4f5556;
            margin: 25px auto;
            color: #EEF;
            padding-left: 10px;
        }
        /* 单独控制登录按钮 */
        .btn {
            width: 302px;
            height: 34px;
            background: url(images/line.png) repeat-x;
            border: none;
            color: #ccc;
            font-family: "微软雅黑";
        }
    </style>
</head>
<body>
    <form action="" method="post" class="list">
        <input type="text" value="请输入手机号"/>
        <input type="text" value="请输入验证码"/>
        <input class="btn" type="button" value="登录"/>
    </form>
</body>
</html>
```

**本节核心知识点：**
- `<form>` 标签属性：`action`（数据提交地址）、`method`（提交方式：get/post）、`name`（表单名称）
- `get` 方式：数据显示在地址栏，有数据量限制，保密性差
- `post` 方式：分段传输，无数据量限制，保密性好（推荐）
- `<input>` 默认为行内块元素，用 `display: block` 转为块元素
- 三种表单控件：`<input />`（多种类型）、`<textarea>`（多行文本框）、`<select>`（下拉列表）

## 案例19：趣味选择题

### example10 — input 控件全类型演示

```html
<!doctype html>
<html>
<head>
    <meta charset="utf-8">
    <title>input 控件</title>
</head>
<body>
    <form action="" method="post">
        用户名：<!-- text 单行文本输入框 -->
        <input type="text" value="张三" maxlength="6"/><br/><br/>

        密码：<!-- password 密码输入框 -->
        <input type="password" size="40"/><br/><br/>

        性别：<!-- radio 单选按钮 -->
        <input type="radio" name="sex" checked="checked"/> 男
        <input type="radio" name="sex"/> 女<br/><br/>

        兴趣：<!-- checkbox 复选框 -->
        <input type="checkbox"/> 唱歌
        <input type="checkbox"/> 跳舞
        <input type="checkbox"/> 游泳<br/><br/>

        上传头像：<!-- file 文件域 -->
        <input type="file"/><br/><br/>

        <input type="submit"/>        <!-- submit 提交按钮 -->
        <input type="reset"/>         <!-- reset 重置按钮 -->
        <input type="button" value="普通按钮"/>  <!-- button 普通按钮 -->
        <input type="image" src="images/login.gif"/>  <!-- image 图像域 -->
        <input type="hidden"/>        <!-- hidden 隐藏域 -->
    </form>
</body>
</html>
```

**本节核心知识点：**

| type 值 | 控件类型 | 说明 |
|---------|--------|------|
| text | 单行文本框 | 常用属性：`value`、`maxlength` |
| password | 密码框 | 内容以圆点显示 |
| radio | 单选按钮 | 同组必须相同 `name`，可用 `checked` 设默认选中 |
| checkbox | 复选框 | 可用 `checked` 设默认选中 |
| button | 普通按钮 | 常配合 JavaScript 使用 |
| submit | 提交按钮 | 提交表单数据 |
| reset | 重置按钮 | 清空所有表单内容 |
| image | 图像提交按钮 | 需指定 `src` 属性 |
| hidden | 隐藏域 | 对用户不可见 |
| file | 文件域 | 出现文本框和"浏览"按钮 |

### example11 — `<label>` 标签的使用

```html
<!doctype html>
<html>
<head>
    <meta charset="utf-8">
    <title>label 标签的使用</title>
</head>
<body>
    <form action="" method="post">
        <label for="name">姓名：</label>
        <input type="text" maxlength="6" id="name"/><br/><br/>

        性别：
        <input type="radio" name="sex" checked="checked" id="man"/>
        <label for="man">男</label>
        <input type="radio" name="sex" id="woman"/>
        <label for="woman">女</label>
    </form>
</body>
</html>
```

**本节核心知识点：**
- `<label>` 标签用于扩大表单控件的点击范围，提升用户体验
- `for` 属性值必须与对应表单控件的 `id` 值一致
- 单击 `<label>` 标签的内容时，对应的表单控件会处于选中/激活状态

### example12 — 案例实现：趣味选择题

```html
<!doctype html>
<html>
<head>
    <meta charset="utf-8">
    <title>趣味选择题</title>
    <style type="text/css">
        /* 重置浏览器的默认样式 */
        body, form, p, label, input {
            margin: 0;
            padding: 0;
        }
        /* 整体控制表单 */
        #list {
            width: 420px;
            height: 474px;
            background: url(images/bg1.png) no-repeat;
            padding: 110px 0 0 110px;
            font-size: 14px;
            font-family: "微软雅黑";

        }
        /* 控制选择题题目 */
        p {
            width: 260px;
            height: 37px;
            padding-left: 50px;
            line-height: 23px;
            font-size: 16px;
        }
        /* 分别为两道题设置背景图 */
        .title1 { background: url(images/num1.png) no-repeat left center; }
        .title2 { background: url(images/num2.png) no-repeat left center; }
        /* 控制选择题选项 */
        label {
            display: block;
            width: 210px;
            padding: 18px 0 0 50px;
        }
        /* 拉开题目间的距离 */
        .one { padding-bottom: 20px; }
    </style>
</head>
<body>
    <form action="#" method="post" id="list">
        <div class="one">
            <p class="title1">渔夫逮到一条美人鱼却把它放了，这是为什么？（单选）</p>
            <label for="choose1"><input type="radio" name="item1" id="choose1"/> 渔夫很善良</label>
            <label for="choose2"><input type="radio" name="item1" id="choose2"/> 养不起美人鱼</label>
            <label for="choose3"><input type="radio" name="item1" id="choose3"/> 违反野生动物保护法</label>
            <label for="choose4"><input type="radio" name="item1" id="choose4"/> 你懂得</label>
        </div>
        <div>
            <p class="title2">在华容道上，关羽为什么没有杀曹操？（多选）</p>
            <label for="choose5"><input type="checkbox" name="item2" id="choose5"/> 因为爱情</label>
            <label for="choose6"><input type="checkbox" name="item2" id="choose6"/> 曹操对关羽有恩</label>
            <label for="choose7"><input type="checkbox" name="item2" id="choose7"/> 关羽不喜欢杀生</label>

</html>
```

**本节核心知识点：**
- 单选题：`type="radio"` + 同组共用相同 `name` 属性

|------|------|
| `<table>` | 定义表格 |

### 重要 CSS 表格属性

| 属性 | 说明 |
|------|------|
| `border-collapse: collapse` | 合并单元格边框（单线效果） |
| `border-collapse: separate` | 分离边框（默认） |
| `padding`（td/th） | 单元格内边距（有效） |
| `margin`（td/th） | 单元格外边距（**无效**） |

### 表单控件速查

| 控件 | 代码示例 | 作用 |
|------|---------|------|
