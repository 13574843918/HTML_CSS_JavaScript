任务二十二

世界杯梦幻阵容

运用 CSS 浮动属性（float）对页面元素重新排列，制作美观整齐的主题展示页面。

预计学习时长：50分钟
float 浮动布局

学习目标

  • 理解元素浮动（float）的概念及其对文档流的影响
  • 掌握 float: left 和 float: right 的使用方法
  • 能够使用多元素浮动实现水平并排布局
  • 理解浮动后元素脱离文档流的规律，能进行图文混排
⚡ HBuilderX 使用技巧 · 本节专属 float & 浮动布局
🏄
float 快速补全

输入 fl:l 按 Tab，自动补全 float: left;；输入 fl:r 补全 float: right;。

📐
margin: 0 auto 居中

输入 m:a 按 Tab，自动补全 margin: auto;，配合宽度让块元素水平居中。

🔍
F12 检查元素

按 F12 打开浏览器开发者工具，选中浮动元素可看到 float 属性，方便调试布局。

📏
width 快速输入

输入 w:200 按 Tab，自动补全 width: 200px;，设置浮动元素宽度更高效。

🎯
ul>li*5 快速生成

在 HBuilderX 中输入 ul>li*5 按 Tab，快速生成带5个子项的无序列表结构。

🔄
即时预览刷新

保存文件后浏览器自动刷新（需开启内置服务器），调整 float 属性时可即时看到布局效果。

01

example 7-1：标签的浮动演示

实训目标：通过演示三个盒子逐步添加 float 属性，观察浮动元素脱离文档流、在同行排列以及产生图文混排效果的全过程。

关键知识点
float: left

元素向左浮动，脱离标准文档流

float: right

元素向右浮动

浮动与文档流

浮动元素不再占用文档流空间，后面的块元素上移

多元素同向浮动

多个左/右浮动元素在同一行排列（宽度允许时）

动手练练
  • 删除 .box01 的 float: left;，观察 box01 回到文档流，box02/03 怎么变
  • 将三个盒子全部改为 float: right;，注意排列顺序与左浮动有何不同
  • 把 .box03 的浮动去掉，观察段落文字 <p> 如何被浮动元素"顶走"
挑战练习
  • 尝试让 box01 左浮动，box03 右浮动，看中间空间如何形成两端对齐效果
02

example 7-2：世界杯梦幻阵容（综合浮动布局）

实训目标：综合运用左/右浮动，实现 Banner 区域两端对齐 + 球星列表水平并排的完整页面布局。理解利用列表 <ul><li> 配合浮动实现横向菜单/展示的常用模式。

关键知识点
左右浮动组合

同一行一个元素左浮动，另一个右浮动，实现两端对齐

<ul><li> + 浮动

使列表项水平排列，常用于导航菜单、图片展示

margin: 0 auto

块级元素水平居中（需设置宽度）

结构分析方法

先分析页面模块（上下/左右关系），再选 HTML 标签

动手练练
  • 修改 #content li 的 width: 100px 为 80px，观察卡片宽度和间距变化
  • 增加一个新的 <li> 球星卡片，看是否自动换行排列
  • 将 .head_r { float: right; } 改为 float: left;，观察两端对齐变为左对齐
挑战练习
  • 在 #head 下新增一个导航栏，用浮动让 4 个导航项目水平排列
拓展练习 · 球星卡片网格

综合运用浮动布局，制作一个 3×3 的球星卡片网格展示区。每张卡片包含球员图标、姓名和国籍，要求卡片等宽、有圆角边框和悬停阴影效果。

  • 任务一：取消 overflow: hidden; 的注释，观察父元素清除浮动影响后的变化
  • 任务二：取消 border-radius: 8px; 的注释，为卡片添加圆角效果
  • 任务三：取消 .card:hover 样式的注释，实现悬停阴影效果
  • 任务四（挑战）：修改 .card 的宽度，让每行显示 4 张卡片而不是 3 张
