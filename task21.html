  • 掌握 span 转为 inline-block 实现标签列对齐
  • 掌握用背景图片美化输入框（background + padding-left）
  • 掌握 <p> 嵌套表单控件使各组控件独占一行

⚡ HBuilderX 使用技巧 · 本节专属 CSS 表单美化
🔄
重置表单默认样式

先写 body, form, input { padding:0; margin:0; border:0; }，消除浏览器差异。

📐
span 对齐标签

将 span 设为 display:inline-block + 固定宽度 + text-align:right，实现标签列整齐对齐。

🎨
背景图美化输入框

设置 background: url(图标) no-repeat 5px center #颜色，再用 padding-left 留出图标空间。

📦
p 嵌套控件

用 <p> 包裹每组表单控件，块级特性使各组自然独占一行，控制间距用 margin-bottom。

form { border:0 }

form 是块元素，重置时需清除 padding/margin/border

input { border:0 }

padding: 2px 2px 2px 22px

文本框加 2~3px 内边距，避免内容紧贴边框

span → inline-block

span 转为 inline-block + 固定宽度，实现左侧标签列对齐

AI实训：让AI完成员工信息录入系统开发

员工档案系统是 HR 系统的基础功能，下方提示词可让 AI 生成一个完整的员工信息录入表单，含个人信息、联系方式、工作信息等多个模块。

📋 提示词范本（可直接复制使用）
请用纯 HTML + CSS 制作一个员工信息录入系统页面，要求如下：

【功能要求，分三个区块】

区块一：基本信息
- 姓名（文本框）
- 性别（单选：男/女）
- 出生日期（日期选择：type="date"）
- 学历（下拉菜单：高中/大专/本科/硕士/博士）

区块二：联系方式
- 手机号（文本框，placeholder="请输入11位手机号"）
- 电子邮箱（邮件框：type="email"）
- 所在城市（下拉菜单，用 optgroup 分华北/华南/华东三组，每组含2-3个城市）

区块三：工作信息
- 所属部门（复选框：技术部/市场部/运营部/人力资源部/财务部）
- 职位（文本框）
- 月薪范围（单选：5000以下/5000-10000/10000以上）
- 个人简介（textarea，高度 100px）

【样式要求】
1. 白色背景，三个区块各有灰色标题栏区分
2. 每行标签宽度固定 90px，右对齐，与输入框紧邻
3. 输入框宽度 280px，有圆角和边框
4. 提交按钮蓝色，重置按钮灰色
5. 整体最大宽度 700px，居中显示

【技术要求】
1. 只用 HTML + CSS，方法="post"
2. 所有表单元素有合理的 name 属性
3. label 与 input 正确绑定（for/id）
4. 代码有区块注释

💡 进阶挑战：完成基础版后，尝试让 AI 再加上"表单验证"功能（必填项标红星 *），或添加"照片上传"区域（type="file" 带预览），进一步提升表单体验。
