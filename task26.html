example 7-13：单列布局

实训目标：理解"版心"概念，掌握单列布局的基本结构。所有内容模块在页面中居中排列，是最基础的网页布局模式。

关键知识点
版心（Container）

页面有效内容区域，通常宽度 960~1200px

margin: 0 auto

上下边距0，左右自动，实现块级元素水平居中

单列布局

所有模块从上到下排列，每模块独占一行

模块命名

top/nav/banner/content/footer 语义化命名

动手练练
  • 修改 width: 980px; 为 1200px，观察版心变宽后的效果
  • 将 margin: 5px auto; 改为 margin: 5px 0;，观察盒子不再居中
  • 给 #top 添加 background: #333; color: white;，美化头部样式
挑战练习
  • 将版心宽度改为 100%（全宽），再在内部新增一个 width: 1200px; margin: 0 auto; 的子容器，实现"通栏背景 + 内容居中"效果
02

example 7-14：两列布局

实训目标：掌握两列布局的实现方法。内容区域分为左右两列，通过 float: left 和 float: right 实现水平排列。

关键知识点
两列布局

左列左浮动，右列右浮动，中间内容区水平分成两部分

宽度计算

两列宽度之和 + 间距 ≤ 父容器宽度，避免换行

overflow: hidden

清除内部浮动，防止父容器高度塌陷

常见比例

侧边栏 25~35%，主内容区 65~75%

动手练练
  • 交换左右两列的浮动方向（左列 float: right，右列 float: left），观察排列变化
  • 将 .content_left 宽度改为 600px，观察是否还能一行放下
  • 给 #content 去掉 overflow: hidden;，观察父容器高度变化
挑战练习
  • 在左列上方添加一个 height: 150px 的广告区块，实现"广告 + 导航"双模块侧边栏
03

example 7-15：三列布局

实训目标：掌握三列布局的实现方法。内容区域分为左、中、右三列，全部使用 float: left（或左左右），注意宽度计算避免换行。

关键知识点
三列布局

左中右三列，常用左+中左浮动、右右浮动

margin 间距

中间列用左右 margin 制造间距，注意总宽计算

浮动顺序

HTML 中先写左列，再中列，最后右列，避免渲染顺序问题

常见比例

左20%、中58%、右20%，留出2%间距

动手练练
  • 将中间列 margin: 0 5px; 改为 margin: 0 20px;，观察布局是否换行
  • 将三列都改为 float: left;（去掉右列的 float: right），观察效果差异
  • 给三个列分别加上不同背景色（如 #fdd、#dfd、#ddf），更直观看到三列分布
挑战练习
  • 将三列布局改为"左列固定 200px + 右列自适应"模式（用 margin-right 代替固定宽度右列）
04

example 7-16：通栏布局

实训目标：掌握通栏布局的设计思路。头部和底部需要"通栏"（宽度占满整个浏览器），但内容仍需在版心内居中，通过"外层 100% + 内层版心"实现。

关键知识点
通栏布局

外层容器 width:100%，内层容器设版心宽度并居中

双层嵌套

通栏盒子内部再套一个版心盒子，内容在版心中居中

常见通栏模块

顶部导航栏、页面底部版权栏常使用通栏背景

background-color

给通栏外层设背景色，内层透明，实现通栏色块效果

动手练练
  • 给 #topbar 设置 background: linear-gradient(...) 渐变背景，美化通栏效果
  • 新增一个通栏广告区（放在 banner 下方），宽度 100%，高度 100px
  • 将 .nav 的文字靠左对齐（text-align: left; padding-left: 20px;）
挑战练习
  • 实现一个"固定顶部通栏导航"：给 #topbar 添加 position: fixed; top: 0;，并给 body 添加 padding-top: 60px; 防止内容被遮挡

example 7-17：网页布局综合案例

实训目标：综合运用单列、三列、通栏等布局模式，制作一个完整的网页结构。理解实际项目中如何用 DIV+CSS 搭建页面骨架。

关键知识点
综合网页布局

头部 + 导航 + Banner + 三列内容 + 底部，完整页面结构

DIV+CSS 思想

用 DIV 划分页面模块，用 CSS 控制每个模块的位置和样式

line-height 居中

设置 line-height = height，实现单行文字垂直居中

语义化命名

top/nav/banner/content/footer 让代码结构清晰易懂

动手练练
  • 将 #top 的背景色改为渐变色 linear-gradient(90deg, #2c3e50, #3498db)
  • 在 #nav 中用 <a> 标签做出4个导航链接，并用 float: left; 让它们水平排列
  • 给 #footer 添加 margin-top: 10px;，让底部与内容区拉开距离
挑战练习
  • 将 #top 改为通栏布局（外层 100% + 内层版心），让头部背景色铺满整个浏览器宽度
