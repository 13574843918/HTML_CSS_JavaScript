任务 27

电影播放界面

运用 HTML5 的 <video> 和 <audio> 标签嵌入多媒体，制作电影播放界面。

50分钟 4个示例

💡 本章节核心目标

HTML5 之前，网页中播放音视频需要依赖 Flash 等第三方插件，存在安全风险、移动端不兼容等问题。HTML5 引入了原生的 <video> 和 <audio> 标签，让多媒体嵌入变得像插入图片一样简单。本任务通过制作一个电影播放界面，带领你掌握音视频标签的完整用法，包括属性配置、多格式兼容处理以及与 CSS 的配合应用。

8-1

嵌入视频

实训目标：掌握 <video> 标签的基本用法，在网页中嵌入并播放视频文件。

关键知识点
<video> 标签

HTML5 新增元素，用于在页面中嵌入视频文件，支持 MP4、WebM、OGG 三种格式。

src 属性

指定视频文件路径，支持相对路径和绝对路径。也可用 <source> 子元素替代。

controls 属性

布尔属性，显示浏览器默认的播放控件栏（播放/暂停、进度条、音量、全屏切换等）。

降级文本

<video> 标签之间的文字，在浏览器不支持该标签时显示，提供友好降级。

替换元素

<video> 类似 <img>，是替换元素，其尺寸受 CSS width/height 控制。

浏览器支持

IE 9+、Firefox 3.5+、Chrome 3.0+、Safari 3.2+、Opera 10.5+ 均支持 <video> 标签。

动手练练
  • 将 controls 属性去掉，观察视频是否还有播放控件。
  • 添加 autoplay 属性，刷新页面观察是否自动播放（注意：Chrome 需配合 muted 才生效）。
  • 修改 width 和 height 的值，观察视频显示区域的变化。
⚡ 挑战练习
  • → 使用 poster="https://www.w3schools.com/images/w3schools_green.jpg" 为视频添加封面图，观察加载过程中封面是否显示。
8-2

video 标签的扩展属性

实训目标：掌握 <video> 标签的扩展属性（autoplay、loop、preload、poster、muted 等），实现更丰富的视频播放控制。

关键知识点
autoplay

页面加载完成后自动播放。Chrome 70+ 禁止有声自动播放，需配合 muted 属性才生效。

loop

布尔属性，视频播放结束后自动重新播放，实现循环播放效果。

preload

预加载策略：auto（预加载整个视频）、metadata（仅加载元数据）、none（不预加载）。

poster

指定视频缓冲不足时显示的封面图片 URL，提升用户体验。仅在视频未开始播放时显示。

muted

布尔属性，静音播放视频。是实现 Chrome 自动播放的必要条件（autoplay + muted）。

playsinline

布尔属性，在移动端（特别是 iOS Safari）内嵌播放，而非自动全屏播放。

动手练练
  • 去掉 muted 属性，观察 Chrome 浏览器是否还能自动播放。
  • 将 preload 改为 auto，用浏览器开发者工具观察网络请求变化。
  • 去掉 poster 属性，观察视频加载前的显示效果。
8-3

嵌入音频

实训目标：掌握 <audio> 标签的基本用法，在网页中嵌入并播放音频文件。

关键知识点
<audio> 标签

HTML5 新增，用于嵌入音频文件，用法与 <video> 基本一致，支持 MP3、OGG、WAV 三种格式。

无画面

音频没有画面，因此没有 poster、width、height 等视觉相关属性。

通用属性

controls、autoplay、loop、preload、muted 等属性与 <video> 语义完全相同。

音频格式兼容性

MP3 格式兼容性最好（所有浏览器均支持），OGG 需 Firefox 支持，WAV 体积较大一般不推荐。

动手练练
  • 添加 autoplay 和 muted 属性，观察音频是否自动播放。
  • 添加 loop 属性，观察音频结束后是否自动重新播放。
  • 将 src 改为一个不存在的路径，观察降级文本的显示效果。
8-4

使用 source 解决浏览器兼容性

实训目标：掌握使用 <source> 子元素为不同浏览器提供多种音视频格式，解决浏览器兼容性问题。

关键知识点
<source> 元素

为 <video> 或 <audio> 提供多个备用媒体文件，浏览器按顺序选择第一个可播放的格式。

src 属性

指定媒体文件的 URL 地址。使用 <source> 时，父元素上不写 src 属性。

type 属性

指定媒体文件的 MIME 类型（如 video/mp4、audio/mpeg），帮助浏览器快速判断是否支持，避免下载后才报错。

兼容性策略

视频推荐使用 MP4 + WebM 双格式；音频以 MP3 为主（兼容性最好）。

降级内容

所有 <source> 都不被支持时，显示标签之间的降级文本（可包含下载链接）。

MIME 类型速查

.mp4→video/mp4；.webm→video/webm；.mp3→audio/mpeg；.ogg→audio/ogg。

动手练练
  • 只保留 type="video/webm" 的 <source>，观察浏览器是否还能播放（取决于浏览器是否支持 WebM）。
  • 在降级文本中添加一个下载链接，让不支持 HTML5 的浏览器用户可以下载视频本地观看。
  • 查阅资料，了解 media 属性的作用（提示：用于响应式媒体查询）。
